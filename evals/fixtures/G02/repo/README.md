# Workspace permission onboarding fixture

The app explains three workspace roles to first-time users. The current page is a long form with all explanations visible at once.

Run tests:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

Run the local app:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 app.py --port 4173
```
