# Cruise Debug

Reproduce or inspect the failure, distinguish root cause from symptoms, implement the smallest justified repair, and verify it. Use normal Codex permissions and explain evidence directly to the user.

Do not create Cruise control-plane YAML, digests, archives, worker reports, or retry ledgers. Keep only the launcher-managed `.cruise/ORIGIN.md` request note.
